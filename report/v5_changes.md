# Draft v5: table titles

7 November 2026. Draft v4 with every table title cut to three to six words, as the figures were in v3. Nothing else changes.

**Rule.** The title names the table. Where the v4 title stated a finding, that sentence now sits word for word in a key-message callout directly above the table, set like the chart callouts (grey fill, cyan rule on the left, bold charcoal). The three executive-summary pillar tables drop only their "Pillar N, name:" prefix in the callout, since the title carries it. Descriptive tables take the title alone: the "findings that carry into the tree" lists, registers, the glossary and the sources.

**Result.** 112 tables retitled; 88 carry a key-message callout and 24 take the title alone. The list of tables now runs one line per table.

**Checks.** All 112 titles are three to six words; all 88 callouts are in the document; the contents map all 185 entries; 635 footnotes intact; every table row renders; DRAFT FOR DISCUSSION on every page; `qa_structure.py` passes with zero issues (its two table look-ups now use the new titles).
